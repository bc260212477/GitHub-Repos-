GitHub Repository Catalogue

This catalogue contains public GitHub repositories returned by GitHub repository searches with stars >= 1,000. Stars indicate popularity only; they are not proof of quality, security, maintenance, or legality. A repository may appear in multiple categories.

GitHub does not expose arbitrary public repository traffic/view counts through this API, so views_data is recorded as unavailable. License metadata is recorded where available; missing or unknown licenses are marked for manual review. No entry claims that a repository is legally or illegally usable.
